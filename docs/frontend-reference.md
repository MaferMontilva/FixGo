# Referencia visual FixGo

FixGo toma de Wolly solo referencias de composicion y experiencia:

- Landing publica con fondo oscuro, header blanco flotante y hero fuerte.
- Marketplace claro con navegacion superior, indicador activo y login a la derecha.
- Buscador grande como accion principal.
- Tarjetas limpias para categorias y profesionales.
- Estados sin sesion con card centrada y CTA visible.
- Login por telefono en una card blanca sobre fondo oscuro.

Adaptaciones propias de FixGo:

- Color primario UX `#F28A2E`, manteniendo el naranja del logo `#FD5C03` solo como referencia de marca.
- Logo FixGo.
- Textos propios en espanol.
- Iconos propios con trazo oscuro y acento naranja.
- Componentes React propios, sin reutilizar codigo ni recursos privados de Wolly.
